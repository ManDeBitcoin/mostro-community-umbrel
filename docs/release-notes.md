Preview.8 incorpora un backup cifrado previo al mercado. `mostro-community-api export-backup` pide una frase en la terminal, cifra la identidad y el borrador con el formato age y verifica el descifrado antes de guardar el archivo privado. `verify-backup <archivo>` confirma la identidad y la configuración sin restaurar ni exponer el nsec. El backup debe copiarse fuera del servidor; todavía no incluye una base de datos de operaciones, ya que Mostro sigue sin instalarse.

El candidato de `settings.toml` deja el nsec vacío y RPC deshabilitado. La imagen opcional de Mostro exige identidad y configuración antes de arrancar. El operador verificó la imagen oficial v0.18.8 en el host con `sudo`; esta release solo publica el Manager. La conexión financiera de LND, la restauración y las pruebas de operaciones completas en regtest siguen pendientes. Se conservan el borrador y la identidad importada al actualizar desde preview.7.
