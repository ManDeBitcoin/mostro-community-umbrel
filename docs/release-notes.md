Vista previa de Mostro Community Manager para Umbrel.

- Panel web y configuración persistente de comunidad.
- Imagen nativa amd64 + arm64; prueba de arranque, guardado y persistencia en cada arquitectura.
- Datos independientes, sin daemon Mostro, sin acceso a LND ni a las claves o DB de instalaciones existentes.
- Entrada a través de `app_proxy` y red interna del Manager.

Para instalar: añadir https://github.com/ManDeBitcoin/mostro-community-umbrel como tienda comunitaria de Umbrel. Antes de instalar, comprobar en el README que la imagen está disponible públicamente y fijada por digest.

Esta vista previa NO inicia un mercado, NO migra una instalación existente y NO gestiona trades ni disputas. Conservar la instalación Mostro actual.
